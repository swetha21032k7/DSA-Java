# Two Sum

## Problem
Given an array of integers `nums` and an integer `target`, return the indices of the two numbers such that they add up to the target.

## Approach
- Used Brute Force Approach
- Checked every possible pair using nested loops.
- If the sum equals the target, returned the indices.

## Time Complexity
O(n²)

## Space Complexity
O(1)
